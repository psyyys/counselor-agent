# 咨询师 A · Counselor_Agent

**不微调模型，靠"约束"做出一个更像专业咨询师的 AI。**

一个认知行为流派（CBT / DBT / ACT）的 AI 心理咨询实验项目。思路是：微调能让模型学会专业咨询师的说话方式、会谈结构和分寸，那能不能**不改模型本身**，只用工作流程、检索和审查把一个通用大模型"约束"成专业咨询师？框架采用华东师大的 [PsychEval](https://github.com/ECNU-ICALK/PsychEval)（arXiv 2601.01802），咨询师的"大脑"用 DeepSeek。

> ⚠️ **这是研究和自我探索用的实验原型，不是医疗器械，不能替代专业心理治疗。**
> 如果你现在有伤害自己或他人的想法，请立刻拨打**全国心理援助热线 12356**（24 小时），紧急情况请拨打 **110 / 120**。

## 特色

### 1. 用"约束"代替"微调"
每一轮对话都走同一条固定流程，而不是让模型自由发挥：

```
来访者说话
 → 危机预检（代码匹配关键词，不花模型调用；命中就附上热线）
 → 检索：相似情境下专业咨询师的示范 ＋ 本次会谈的候选技能 ＋ 治疗手册片段
 → DeepSeek 先写思考（评估 / 来访者状态 / 用哪个技能 / 策略 / 风险），再写回复
 → 督导审查（CTRS 六个维度 ＋ 硬性规则）── 不通过就重写一次
 → 回复来访者
```

| 微调能带来的 | 本项目用什么替代 |
|---|---|
| 说话风格 | 检索 PsychEval 里 2.5 万句专业咨询师发言作为示范 |
| 会谈结构 | 三阶段疗程 + 每次会谈的议程（照搬 PsychEval） |
| 专业技能 | CBT 技能库 1171 条（PsychEval）+ DBT / ACT 技能库（可从你自己的手册抽取） |
| 分寸和底线 | 第二个模型当督导，逐句审查：一次只问一个问题、不诊断、不说教、不越出流派…… |

### 2. 会记得你
每次会谈结束，自动写会谈总结、更新个案档案（核心信念、情境—想法—情绪链）、生成疗程计划，下次接着聊。档案在网页上可以查看、修改、导出。

### 3. 能打电话
- 像打电话一样直接说话：**说多久都行**（长段话自动分段识别），停顿后自动回应，也可以点「我说完了」或开启"由我决定什么时候说完"
- 咨询师说话时你一开口他就停下来听（可关闭）
- **声音线索**：根据语速、停顿、音量的变化（和你自己本次通话的平均水平比），提示咨询师"他说这句时慢了很多、停了好几次"。只当作需要和你确认的线索，不下情绪结论；**不额外调用模型**
- 声音、风格（成熟沉稳 / 温厚 / 低柔）、语速都可以调

### 4. 给来访者自己看的「我的记录」
心情变化曲线（每次会谈前后签到）、这周的练习打卡、我的想法地图、只有自己看得到的随手记、可以回看对话的会谈时间线。

### 5. 照顾人的细节
随时可见的求助热线、一分钟呼吸练习、快捷短语（"我不知道该怎么说"）、等得久时说明原因、字号/主题/减少动画等设置。

### 6. 可评测、结果如实记录
接入 PsychEval 的 9 项指标（CTRS、WAI 等），用 PsychEval 案例模拟来访者，比较"只加一句提示词的同一模型 / 咨询师 A / PsychEval 原对话"，并额外检查风险评估。

第一轮结果（3 个案例，见 [docs/评测记录.md](docs/评测记录.md)）：**按 PsychEval 分数，咨询师 A 没有胜过只加提示词的模型**；但评委连 PsychEval 自己的标准对话也判输了，明显偏爱长回复，而且这些指标不考察安全——有自杀念头的来访者，只有咨询师 A 和标准对话做了风险评估。评委的可靠性还需要改进。

## 快速开始

### 1. 准备
```
pip install -r requirements.txt
```
复制 `config.example.json` 为 `config.json`，填入阿里云百炼的 API Key 和模型名（OpenAI 兼容接口，其他兼容服务也可以）。

### 2. 下载 PsychEval 数据（范例库和技能库的来源，CC BY-NC 4.0）
```
git clone --depth 1 --filter=blob:none --sparse https://github.com/ECNU-ICALK/PsychEval.git third_party/PsychEval
cd third_party/PsychEval && git sparse-checkout set data/cbt eval && cd ../..
```

### 3.（可选）放入你自己合法获得的治疗手册
把 PDF 放进 `data/kb_raw/cbt/`、`data/kb_raw/dbt/`、`data/kb_raw/act/`。本仓库**不包含**任何书籍或由书籍改写的内容。
```
python -X utf8 -m counselor.build_skills      # 从 DBT / ACT 手册抽取技能库（会调用模型）
```

### 4. 建检索库并启动
```
python -X utf8 -m counselor.build_index
python -X utf8 -m uvicorn counselor.server:app --host 127.0.0.1 --port 8765
```
Windows 可以直接双击 `启动.bat`。浏览器打开 http://127.0.0.1:8765 。

### 模型
| 用途 | 默认 | 说明 |
|---|---|---|
| 咨询师 / 督导 | DeepSeek | 建议固定版本号，升级前后各跑一次评测 |
| 语音识别 | qwen-audio-3.0-asr-flash | 返回逐词时间，用于声音线索 |
| 朗读 | qwen-audio-3.0-tts-plus | 音色和风格在网页设置里调 |

## 目录
```
counselor/          核心：会谈流程、检索、记忆、安全预检、语音、后端
web/index.html      网页界面（对话、语音通话、我的记录、设置）
experiments/        评测：模拟来访者、PsychEval 指标、成对比较
docs/               设计文档、数据来源调研、评测记录
tests/              离线测试（假模型）；tests/fake_server.py 可无 Key 预览界面
```

## 数据与隐私
- 会谈记录、个案档案、心情和随手记都只存在本机 `data/users/`
- 对话内容会发送给你配置的模型服务商（例如阿里云百炼），请自行评估
- 随手记不会发给模型
