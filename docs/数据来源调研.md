# 范例对话数据来源调研

原则（用户 2026-10-21）：**范例绝不自己编写**，只用公开的已有数据，避免污染。
本项目仅本地实验使用、不再分发。

## 二、PsychEval 的结构（最匹配本项目）
每个案例 JSON 包含：
- `client_info`：基本信息、主诉、成长经历；动力学案例还有**核心冲突（愿望/恐惧/防御）**、**客体关系**、行为反应模式+防御机制；CBT 案例有**核心信念**
- `global_plan`：三阶段——问题概念化与目标设定 → 核心干预 → 巩固与复发预防
- `sessions[]`：每次会谈的目标、建议技能（元技能+微技能，含"何时使用"）、**逐轮对话**（咨询师每句带 `<think>`：评估/来访者状态/所用技能/策略）、会谈总结、**来访者信息更新**、下次计划
- 论文还提供 18 项评测指标 → 可直接当实验评测

## 三、排除或降级
- **CPsyCounD**（3134 段）：LLaMA-Factory 格式，**每条没有流派标签**，无法按流派筛选；抽样可见过早下结论的回复 → 不用
- **SMILE**：ChatGPT 由 PsyQA 扩写，偏安慰型 → 不用
- **DiaCBT**：数据未公开
- DBT：无公开对话数据；ACT：仅 Psy-Insight 英文 8 段 → 按用户决定放弃

## 四、真正"真实录音转写"的来源（目前都难拿到）
- Psych8k：约 260 次真实咨询录音转写，英文，需申请，CC-BY-NC-SA
- Alexander Street 咨询转写库：真实会谈，含精神分析等流派，需机构订阅

## 五、授权
- PsychEval：仓库无标准许可证（NOASSERTION），论文写明"仅限学术研究、负责任使用"
- Psy-Insight：继承源数据 MIT/Apache 等
- Cactus：GPL
